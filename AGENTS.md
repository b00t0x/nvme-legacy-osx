# Repository guidance

This repository contains public documentation and reproducible tooling for the
NVMeGeneric legacy macOS compatibility patches.

- Keep third-party NVMeGeneric binaries, kext bundles, packages, release
  archives, and locally obtained inputs out of Git history.
- Public tooling may generate only the promoted Mavericks and Snow builds.
- Keep English and Japanese documentation aligned.
- Store generated output under `build/` or `dist/`.
- Preserve the upstream copyright and embedded notice. The repository license
  covers only this project's original scripts and documentation.
